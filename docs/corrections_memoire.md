# Guide de Corrections pour le Mémoire

## Instructions : Ouvrez votre fichier Word/LaTeX du mémoire et appliquez les corrections suivantes.

---

## 1. Correction des notes de bas de page en double

### Problème 1 : Note "ITSM" utilisée deux fois

**Page 1 (Chapitre 1) :** 
- Note 1 : ITSM → laisser telle quelle  
- Note 5 : ITSM → **Remplacer par une nouvelle note**

**Solution :** Remplacer la note 5 (page 3, dans la section "Définitions relatives au domaine") par :
```
5. ITIL v4 : Information Technology Infrastructure Library version 4, référentiel de bonnes pratiques pour la gestion des services IT.
```

### Problème 2 : Note "Workflow" utilisée deux fois

**Page 2 (Chapitre 1) :**
- Note 6 : Workflow (fin de page 2) → laisser telle quelle

**Page 3 (Chapitre 1) :**
- Note 6 : Workflow (dans les définitions) → **Changer le numéro ou la définition**

**Solution :** Changer la définition du workflow page 3 en :
```
6. Automatisation des processus : Technique permettant d'exécuter automatiquement une séquence d'opérations sans intervention humaine, basée sur des règles prédéfinies.
```

### Problème 3 : Note "NLP" utilisée deux fois

**Page 1 (Chapitre 1) :**
- Note 5 : NLP (page 1, note de bas de page 5) → laisser telle quelle

**Page 3 (Chapitre 1) :**
- Note 5 : NLP (page 3, dans les définitions) → **Changer**

**Solution :** Remplacer la définition de NLP page 3 par :
```
5. TALN : Traitement Automatique du Langage Naturel, discipline à l'intersection de l'informatique et de la linguistique computationnelle.
```

## Instructions finales

1. **Ouvrez votre document source** (Word/LaTeX)
2. **Appliquez chaque correction** dans l'ordre ci-dessus (comptez ~15 minutes)
3. **Regénérez le PDF** après corrections
4. **Vérifiez** que la numérotation des notes de bas de page est cohérente après les modifications
5. **Imprimez/Vérifiez** que le tableau des matières est à jour
